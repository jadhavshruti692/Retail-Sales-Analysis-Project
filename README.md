# End-to-End Retail Sales & Profit Optimization Analysis

## 📌 Project Overview
This project analyzes retail sales data (9,990+ orders) to identify key profit drivers, loss-making products, and the impact of discounting on overall business profitability.

## 🛠️ Tools & Technologies Used
* **Python (Pandas, NumPy, Matplotlib, Seaborn):** Data cleaning, feature engineering, and exploratory data analysis (EDA).
* **SQL (MySQL):** Business querying using aggregations, `GROUP BY`, and `CASE WHEN` statements.
* **Microsoft Excel:** Interactive dashboard using Pivot Tables, Pivot Charts, and dynamic Slicers.

## 💡 Key Business Insights
* **Discount Impact:** Discounts exceeding **20%** in the Furniture category (especially Tables) resulted in significant financial losses.
* **Regional Performance:** The **West** region generated the highest sales and profit across all years.
* **Growth Trend:** Overall company sales showed a steady upward trend year-over-year.
